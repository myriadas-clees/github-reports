# Current theme source references

These files are copied from Myriad Apps `origin/main` revision `c48e160faa3ac240e7416deea1fe41b2a24ed12e` for design reference. They are not imported by Worklog. `graphical-theme.css` contains the current light and dark token definitions; `styles.css` contains Myriad aliases and shared component rules.

The copied `styles.css` omits source-monorepo-only imports and directives (`fonts.css`, Tailwind, and its `ui/` scan path). Worklog uses its existing renderer CSS and theme architecture. `fonts.css`, the font files in `assets/fonts/`, and their OFL licenses are included as references for self-hosted typography. Source monorepo build infrastructure was not copied.
